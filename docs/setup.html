Setup

Three optional steps after installing. Each one is a few adb commands.

Default Home

Use the scripts in tools/ in the repo. debloat.ps1 disables the stock launcher so Lucerra becomes Home; restore.ps1 undoes it.

Remote apps button

Enable the accessibility service so the apps button opens All Apps:

adb shell settings put secure enabled_accessibility_services dev.raj.lucerra/dev.raj.lucerra.KeyService
adb shell settings put secure accessibility_enabled 1

Now Playing widget

Grant notification access so the widget can read Spotify or any media session:

adb shell cmd notification allow_listener dev.raj.lucerra/dev.raj.lucerra.NowPlayingListener

Lucerra declares no network permission. These services only read key events and media sessions on the device.
