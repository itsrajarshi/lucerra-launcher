Install

Lucerra is sideloaded over adb. You need a computer on the same network as the TV and Android platform-tools.

1. Enable network debugging

On the TV: Settings, Device Preferences, About, press Build several times to unlock developer options. Then turn on USB debugging (network debugging on some boxes).

2. Connect and install

Download Lucerra-Launcher-v0.1.0.apk from the GitHub release, then run:

adb connect <tv-ip>:5555
adb install -r Lucerra-Launcher-v0.1.0.apk

Accept the debugging prompt on the TV the first time you connect.

Next: make it your default Home.
